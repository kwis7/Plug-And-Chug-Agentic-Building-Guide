# A short starting prompt / 简短起步提示词

Give your assistant a local copy of this repository, or this link if it can read public repositories: <https://github.com/kwis7/Plug-And-Chug-Agentic-Building-Guide>. A link alone does not grant file access. If the tool cannot read the repository or save local files, ask for a preparation plan and provide only the specific non-sensitive text needed.

把本地仓库位置告诉助手；如果它能读取公开仓库，也可以提供上面的链接。链接本身不会授予文件权限。工具无法读仓库或保存本地文件时，先做准备方案，只提供当前需要的非敏感文字。

## English

```text
Use this repository to help me organise one recurring task I do with AI.
First understand the result I need, where I usually get stuck, and which tool
I use. Ask two or three questions at a time, recommend the smallest useful
approach, and explain why. Check which local files you can actually read and
write. Show the exact target folder and changes for my approval before creating
files. Help me finish and check one task, then leave a note for the next session.
After that, decide with me whether more agents or automation would help.
```

## 中文

```text
请用这个仓库帮助我整理一项经常交给 AI 的工作。先了解我想完成什么、
现在通常卡在哪里，以及我在用哪个工具。每次只问两三个问题，推荐最小
可用的做法，并解释原因。先确认你实际能读取和写入哪些本地文件。
创建文件前，列出准确的目标目录和具体改动，请我确认。先带我完成并
检查一个任务，留下下次继续的说明，再一起决定是否需要更多 Agent 或自动化。
```

Start with the [English learning example](https://github.com/kwis7/Plug-And-Chug-Agentic-Building-Guide/blob/main/examples/first-project/README.md) or [中文学习案例](https://github.com/kwis7/Plug-And-Chug-Agentic-Building-Guide/blob/main/examples/first-project/README.zh-CN.md) if you want to try supplied fictional material first.

For an assistant conducting a longer design interview, the original detailed instructions are preserved in the [full facilitation protocol](facilitation-protocol.md). It is a reference for the facilitator; you do not need to paste all of it to begin. If the skill is installed and discoverable, the assistant can use [its entrypoint](../../SKILL.md).
