# Guided setup: facilitator entry

The guided conversation is maintained in the [facilitator protocol](facilitation-protocol.md). Use that reference for the shared sequence: understand one recurring job, agree on a small setup, build, check a first result, try recovery and leave a next-use card.

Give the user the [short starting prompt](friend-starter-prompt.md). They do not need to paste a workshop script or complete the full questionnaire. Start with one Agent unless their work shows a reason to separate responsibilities.

This entry is retained for existing links; the protocol is the authoritative guide for facilitation.
