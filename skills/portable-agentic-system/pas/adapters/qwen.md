# Qwen / Alibaba Cloud Model Studio Provider Profile

Classification: model API provider
Repository verification: `provider_only`

Official documentation:

- https://help.aliyun.com/en/model-studio/what-is-model-studio
- https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope

Qwen endpoints and available models vary by region, workspace, and account. Keep base URL and model ID configurable and date-stamp any tested combination. A compatible API surface does not make Qwen a local harness runtime; the caller owns entrypoint loading, tools, persistence, verification, and writeback.
