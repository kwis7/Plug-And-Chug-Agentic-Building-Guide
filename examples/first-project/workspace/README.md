# Your working files / 你的工作文件

Create `comparison.md` for the draft and `handoff.md` for current progress during the exercise. A resumed session creates `maple-question.md`; the separate failure exercise creates `missing-source-check.md`.

These learner files are intentionally absent from the supplied example. Reference answers live in `../expected/`; do not present them as outputs your tool actually produced. Preserve existing learner files when restarting.

练习时创建草稿 `comparison.md` 和进度交接 `handoff.md`；续做会创建 `maple-question.md`，单独的缺失资料练习会创建 `missing-source-check.md`。

仓库刻意没有预填这些学习者文件。参考答案位于 `../expected/`，不能将其声称为工具实际完成的产物。重新开始时保留已有工作。
