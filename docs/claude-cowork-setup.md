# Claude Cowork Setup

Claude Cowork is a workspace agent, not simply Claude Code without a terminal. Use Cowork projects and folder instructions rather than assuming the Claude Code `CLAUDE.md` import chain is the project contract.

Official documentation:

- https://support.claude.com/en/articles/13345190-get-started-with-claude-cowork
- https://claude.com/docs/cowork/guide/projects

## Setup

1. Create one Cowork project for a recurring domain.
2. Attach only that domain's local folder.
3. Put the compact common contract in project/folder instructions.
4. Add only relevant links, reviewed references, and skills/plugins.
5. State whether Cowork project memory or local `MEMORY.md` is authoritative for durable recovery.
6. Keep task contracts and reviewed outputs in the mounted folder when local writeback is enabled.
7. Test folder boundaries, deletion confirmation, connector access, skill/plugin scope, writeback, and closeout on non-sensitive fixtures first.

Cowork sessions may run remotely and reach local files through the desktop app. Review current network, file, retention, project, connector, and organisation settings before using private material.
