# 从一个任务开始

[English](start-here.md) | [中文](start-here.zh-CN.md) · [首页](../README.zh-CN.md)

你会比较三份虚构场地资料，核对结果，再开一个新会话继续。完成后，草稿、核对后的比较表和简短交接说明都会保存在可查看的文件里。

这是一个学习案例。它不生成标准 Harness，不安装 Skill，不改个人设置，也不联系任何场地。

## 开始前需要什么

你需要一份本地仓库副本，以及能读取你选定文件的 AI 工具。让工具保存练习，还需要允许它写入 `examples/first-project/workspace/` 和 `examples/first-project/outputs/`。继续用你已有的工具即可，无须更换模型服务。

如果使用 Git，[快速开始的第 1 步](../QUICKSTART.zh-CN.md)中有克隆仓库和进入目录的命令。这条学习路线到这里就够了，不需要 Python，也不运行生成器。你也可以自行下载并解压一份仓库副本。

如果工具只有聊天功能，没有本地文件权限，可以粘贴三份虚构资料和任务说明，让它协助比较，再由你保存文件。这只能练习分析过程，不能验证本地读取或自动续做。工具订阅或 API 调用可能另行收费。

## 开始练习

在工具中打开本地仓库，或者告诉它仓库的准确本地路径，然后粘贴：

```text
请带我完成 examples/first-project/README.zh-CN.md 中的学习练习。
先读这份教程、task-brief.md 和 sources/ 下明确列出的三份资料。
我要求对照参考答案之前，不要读取 expected/。
只使用这些虚构资料，不上网、不联系任何人、不预订场地。
把我的草稿和交接说明保存在 workspace/，核对后的结果保存在 outputs/。
保留资料原文和参考答案。如果目标文件已存在，先查看并商量如何继续，
不要直接覆盖。告诉我实际读取了哪些文件，以及怎样核对比较结果。
完成后带我做一次新会话续做练习。
```

[案例教程](../examples/first-project/README.zh-CN.md)列出了准确文件名、核对标准和新会话提示词，还安排了一次资料缺失练习：有用的助手应该说清缺口，不能凭空补出不存在的信息。

完成标准是：保存的比较结果忠于资料，未知项仍然清楚可见，新会话能通过交接说明找到下一步。工具说“已保存”还不够，要打开文件看内容。没有实际做新会话练习时，续做能力应标为**未测试**。

## 用到自己的工作中

先选一项反复做的任务，提供少量非敏感且允许交给工具处理的资料。[简短起步提示词](../skills/portable-agentic-system/pas/references/friend-starter-prompt.md#中文)会让助手先了解你想要的结果、现在卡住的地方和工具能力，再提出具体改动。

想理解每一步，继续读[手册](handbook/index.md)。想使用现成的完整标准结构，选[手动工具包路线](../QUICKSTART.zh-CN.md#manual-standard-scaffold)。生成器是另一种规模更大的设置；这个小案例不是生成器的“最小模式”。
